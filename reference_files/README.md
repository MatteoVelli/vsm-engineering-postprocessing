# Runtime reporting assets

Keep this folder with the application. It contains Astauto branding, PowerPoint
layout references and Excel channel-mapping templates required by the tool.

Current October profiles use:

- Robo_Sprayer_Electrification_Tamplate_Electric_08.xlsx
- Robo_Sprayer_Electrification_Tamplate_Hybrid_08.xlsx
- Diesel Template_04.xlsx

Electric_05 and Hybrid_06 remain for the explicit legacy reporting option.
Electric_03 and Hybrid_04 remain for the existing reference-based analysis and
health checks. PowerPoint templates and astauto-light-text_web.jpg preserve the
established slide layouts and logo. Do not rename or remove runtime assets.

Private raw simulation exports and generated reports are not included. Upload
VSM CSV or Excel results through the application. First-time setup and normal
use are explained in README_SERGIO.txt at the extracted package root.
