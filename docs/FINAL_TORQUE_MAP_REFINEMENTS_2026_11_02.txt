Sergio's manual workflow

1. On Motor Curves, enter actual motor-shaft RPM/torque in A/B, starting at
   row 11, and the curve name in B9. Record manufacturer/model, source revision,
   peak/continuous classification and operating conditions at the right.
2. Right-click the matching chart on Torque Maps, choose Select Data > Add,
   and select the populated speed cells as X and torque cells as Y. Select
   only populated rows. Rows 11–210 are preformatted; extend below if required.
3. Give the new XY series a solid line if desired. Keep the simulation series
   as point clouds. Each additional curve can have its own RPM vector.
4. For the wheel chart, enter already converted wheel-side RPM/torque in D/E
   and its name in E9. Record the conversion authority.
5. Copy the finished Excel chart into PowerPoint. Microsoft's recommended
   self-contained option is Keep Source Formatting & Embed Workbook. A picture
   paste loses editability; Link Data instead requires the source workbook to
   remain available. Some versions also offer an Excel OLE paste option.

Engineering constraints

Motor-shaft capability curves may be compared only at the corresponding motor
shaft and with compatible units and operating conditions. Motor-shaft curves
must not be labelled as wheel-side envelopes without converting BOTH RPM and
torque for verified gearing, efficiency, topology and power-flow direction.

The application does not contain verified general drivetrain conversion
parameters and performs no such conversion. Ratios inferred from an individual
simulation are not adopted as manufacturer capability parameters. The user must
supply correctly converted wheel-side curves. No motor-selection subsystem or
new dependency was added.

Office limitation, stated precisely

This installed Office version rejects the OLE-specific clipboard format. Its
native chart paste works, retains all five series and displays correctly, but
keeps a link to the source workbook even when the automation requests no link.
ChartData.IsLinked and the saved presentation's external chart relationships
were inspected to establish this. Self-contained GUI Embed Workbook is documented
from Microsoft guidance but is not claimed to be verified by this automation.
Use that explicit GUI option for portable slides; retain the workbook when using
the linked option. This is a copy/paste mode distinction, not a numerical or
Excel chart editability defect.

investigation remains unchanged. These refinements do not invent missing inputs.
