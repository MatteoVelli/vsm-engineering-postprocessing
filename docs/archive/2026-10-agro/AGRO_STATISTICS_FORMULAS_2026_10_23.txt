Targeted Excel Statistics Value formulas - 23 October 2026
=========================================================

This change adds actual Excel formulas in the Value column, not mathematical
descriptions in Definition cells. It preserves the preceding general source
policy and machine-specification corrections already in this working tree.

Finding
-------
The preceding shared _write_net_mass_rate_formula() already replaced available
Capacity values with MAX('Agro Mass Source'!B5:B<last>) and available kg/km with
a live endpoint formula. L/m and kg/m still contained static Python results.
Unavailable Capacity/L/m/kg/m cells were static N/A text. The new shared writer
handles all three requested Value cells, including formula-valued N/A cases.
Existing kg/km formulas and Python numerical calculations are unchanged.

Implementation
--------------
src/vsm_postprocessing/agro_excel_formulas.py (new):
  write_agro_statistics_formulas() writes the three Statistics Value formulas
  using the dynamic reporting-metric row registry. It references the canonical
  Agro Mass Source worksheet, whose B column already contains either =-Arow/9.81
  or =Arow for the configured force/direct source. Capacity is a guarded MAX.
  The mass diagnostic is initial minus final mass / (last minus first distance).
  The volumetric inference additionally divides by a referenced density parameter
  initialized from ReportingInputs with its existing provenance. No density is
  assumed. Missing density yields N/A inside an actual formula.

  Helpers append to the existing hidden Formula Support sheet, without moving
  existing columns or parameter cells. Distances convert to meters as required.
  COUNT/ROWS, MIN and SUMPRODUCT guards check aligned numeric samples, valid sign,
  nonnegative and monotonic cumulative distance, positive travelled distance and
  nonincreasing mass. Nonzero absolute step helpers implement the existing >=5
  steps and >20 times median discontinuity rule; zeros become text blanks that
  MEDIAN ignores. IF prevents evaluation of an empty median. IFERROR catches
  missing/error cells and numerical errors. Inferred all-zero force is unavailable;
  explicitly configured direct kg zero contents remain valid.

  A missing or unsupported configured mass source produces ="N/A"; it never
  fabricates a source or number. Existing configured direct cumulative volume and
  integrated volumetric flow modes retain their source selection and formulas
  over their actual samples. An invalid selected volumetric source cannot fall
  back silently to a mass/density inference.

src/vsm_postprocessing/excel_report_engine.py:
  Calls the new shared writer after the existing profile KPI formula compiler.
  Removes the duplicate capacity assignment from the kg/km writer. The existing
  kg/km calculation/writer otherwise remains unchanged. Main report layout,
  Statistics row positions, borders, number formats, metadata and provenance are
  retained. No change to agro_reporting.py or validated math is part of this task.

tests/test_agro_excel_formulas.py (new):
  37 regressions: three profiles, force/direct sources, sample counts 2/7/31,
  meter/kilometer distances, nonzero origins, missing density, zero/reversed/
  negative/discontinuous distance, refills, mass jumps, negative contents,
  missing/zero/nonfinite/wrong-unit force, missing distance, direct volumetric

scripts/validate_agro_statistics_formulas.py (new):
  Regenerates the four reference workbooks using the previous audit's sources,
  profile paths, report selections and explicit inputs. Records metric cell
  coordinates, formula strings, types, cache values and source hashes. Also makes

scripts/validate_agro_statistics_formulas_excel.ps1 (new):
  Opens disposable copies read-only in desktop Excel, runs CalculateFullRebuild,

Recalculation and cache behavior
-------------------------------
The unchanged write_formula()/save_report_workbook() architecture writes genuine
OOXML <f> elements and deterministic Python-derived numeric or string caches.
data_only=True readers therefore receive initial values, including N/A text.
openpyxl does not calculate formulas. Workbooks request auto calculation,
fullCalcOnLoad and forceFullCalc. Desktop Excel recomputes the dependencies and
writes its own caches when saved. A third-party openpyxl load/save can discard
formula caches; such a reader must recalculate in Excel or use this repository's
cache-writing path. Cached agreement alone is not claimed as Excel evaluation.
