Template-driven agrochemical reporting simplification - 24 October 2026
======================================================================

Historical partial-removal record. The final removal of source controls and all
dedicated source worksheets is documented in AGRO_SOURCE_FEATURE_REMOVAL_2026_10_24.txt.

Scope and findings before editing
---------------------------------
The supported profiles already selected force_inference automatically, through
the configured agrochemical_discharge_force semantic mapping to
HitchRear_Force_Z_VehicleCoordinates [N]. Hybrid inherits the common Electric
mapping; Diesel has its own explicit reporting mapping. No new machine matching
or filename-based exception was needed. Direct kg sources still require an
appropriate profile/API configuration with provenance; arbitrary forces are not
guessed to be chemical mass.

The unnecessary exposure was in two places:
1. Accessing general advanced settings/density also displayed the source-policy
   selector, semantic/raw-header source field and policy provenance. Confidence
   and volumetric-source controls were mixed into those general settings.
2. Every numerically available mass source produced a visible Agro Mass Source
   worksheet duplicating raw force and calculated mass, even when the main
   report already held the correct live source/MATH columns.

Implemented behavior
---------------------
Normal workflow remains upload -> profile/output selection -> generate.
Battery Pack Mass and density retain their previous behavior. Agro source policy
and physical confidence now require a separate, optional 'Override agrochemical
source configuration' checkbox inside Advanced Configuration. Density alone does
not expose or change those fields. Profile defaults remain automatic; the user
does not need to approve a physical interpretation to obtain qualified inference.

Before writing workbook charts/formulas, the exporter resolves the actual source
channel ID to exported semantic columns. It reuses the main calculated mass only
when the source identity, expression (-Fz/9.81) and deterministic sample arrays
match the selected reporting method. A directly configured kg source can be used
directly from its exported main column. Statistics and charts share this binding.

For the normal Electric/Hybrid force configuration with exported source, mass and
distance, Agro Mass Source is removed entirely. Existing main raw/MATH columns,
their formula caches, their order and the user's independent selections remain.
When an input is not exported or the legacy MATH convention differs, the existing
source helper is retained HIDDEN. It links to main inputs where possible. This
supports direct kg channels omitted by a fixed template and minimal channel
exports, without forcing columns into the main report. It also preserves the
separate canonical 9.81 reporting calculation when legacy Diesel MATH uses
9.80665. No validated legacy expression, array or statistic is rewritten.

All four reporting Value cells are actual formulas, including unavailable kg/km:
  agro_capacity_observed_kg
  agro_discharge_rate_L_per_m
  agro_mass_discharge_rate_kg_per_m
  agro_discharge_rate_kg_per_km
Rows, column references and sample extents are dynamic. The existing distinctions
remain: kg/m and density-derived L/m use travelled distance; net kg/km uses the
final cumulative distance and can retain a refill warning. Missing density is N/A.
Monotonicity, missing/negative contents, nonfinite values and discontinuity checks
retain their established meanings. Excel guards enforce those distinctions.

No calculated observed maximum is labelled nominal tank capacity or measured
chemical contents. Source policy, assumed interpretation, quality status and
provenance remain in reporting metadata and notes. Visible/hidden sheet lists and
new workbook-source coordinates now describe the actual generated workbook.
PowerPoint templates/design and the plotting/numerical engines are unchanged.
