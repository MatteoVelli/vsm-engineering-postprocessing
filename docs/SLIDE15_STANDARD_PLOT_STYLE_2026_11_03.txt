Scope and implementation
Only the slide-only chart renderer and its regression tests changed for this
request. Earlier engineering, Excel, GUI and presentation changes remain intact.

src/vsm_postprocessing/torque_maps_presentation.py:
- Removed _layout_torque_map_chart and its custom title/legend header band,
  figure-relative legend anchor, axes rectangles and margin fitting loops.
- render_torque_maps now follows plotting_engine._render_one_plot: standard
  Figure construction, title fontsize 15 and pad 12, default title position
  and font properties, normal tight_layout, standard grid colour and spines.
- Uses the existing _apply_axis_format and _draw_zero_line helpers. Tick
  formatting now matches standard report unit formatting, with a zero reference
  where signed torque crosses zero. Original data-derived limits are unchanged.
- Legends use the standard 'best' location inside the axes, 9-point text,
  white frame at alpha 0.92 and #B8C2CC border. Two columns accommodate the
  four measured series plus grouped positive/negative capability entries.
- Original scatter coordinates, colours, orange peak lines, teal dashed
  continuous lines, labels and numeric provenance are unchanged.

tests/test_torque_maps_presentation.py:
- Replaced assertions for the explicitly rejected external legend band with
  full legend containment inside the numeric axes, for full and partial inputs.
- Retained canvas, title, plot-area, signed-value, line-style, source immutability,
  native-series, numeric-range, KPI aggregation and missing-input protections.
- Added direct style comparison with the actual normal _render_one_plot:
  title font family/size/weight, title position/alignment/padding transform,
  axis/tick fonts, legend font/frame/location, grid, spines and layout engine.
- Tests account explicitly for the standard zero reference, separately from
  the unchanged four capability lines.
