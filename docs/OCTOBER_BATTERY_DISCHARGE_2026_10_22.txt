October battery pack mass and agrochemical discharge update - 22 October 2026

Implementation
--------------
Battery pack mass (kg) is an optional manual field in Electric/Hybrid report
configuration. Streamlit retains its value through reruns using the existing
session-state widget mechanism. reporting_inputs carries battery_mass_kg,
battery_mass_status=user_provided, and provenance=Manual report input through
resolve_report_metadata and generate_reporting_profile_engineering_report to
Excel and PowerPoint. Blank input displays N/A. Nonpositive, nonnumeric, boolean,
NaN and infinite values are rejected by ReportingInputs validation. Known machine
configurations no longer supply preset battery masses. Diesel has no mass field.

PowerPoint uses the existing KPI slot expansion/fit implementation to clone the
seventh card at the right end of the Battery & Electrical Energy System row.
The cloned card retains background, font runs, accent, shadow and internal
margins. All seven backgrounds occupy x=0.60..12.73 inches at y=1.72 inches on
the existing 13.333 x 7.5 inch slide. The previous mass footnote is removed.
Status and provenance remain in manifests/slide notes, not in the numeric card.

Net agro discharge uses (initial mass - final mass) / final cumulative km.
agro_reporting.calculate_net_mass_discharge_rate is the shared deterministic
calculator. calculate_reporting_kpis obtains remaining mass from the existing
agrochemical_discharge mathematical channel and distance from the semantic
track_distance resolution. Existing kg source channels can supply mass directly
when the force-derived channel is absent; no second force conversion is applied.
The unchanged profile expressions use -force/9.81 for Electric/Hybrid and
-force/9.80665 for Diesel. Math-channel selection retains this optional dependency.
No new source channel is made required.

Finite aligned simulation data and nonnegative contents are required. Negative
net discharge, invalid endpoints/units, missing channels, and nonpositive final
distance produce an unavailable metric with an actionable warning. Nonzero
starting distance and increases in remaining contents produce warnings. Refill
increases are never summed into cumulative discharge; the specified net endpoint
formula remains in force. Zero net discharge is a valid measured result.

Excel receives a reusable agro_discharge_rate_kg_per_km reporting metric in
Statistics and the existing report summary. When its source columns are exported,
a live formula references their semantic positions and dynamic last sample row,
with a deterministic cache matching Python. Other source selections retain the
calculated value without broken formulas. PowerPoint displays the shared result
to two decimals with kg/km, on the existing agro slide or Diesel executive slide.
The older volumetric and kg/m diagnostics remain separate in Excel/metadata.

Limits
------
Private reference workbooks are optional in source-only checkouts; their tests
skip explicitly when unavailable. Existing required source/time validation still
applies. Invalid optional agro data displays N/A and a warning. No refilling-cycle
segmentation or density inference is introduced. The available real Caiman CSV
has negative inferred contents and therefore cannot demonstrate an available
mass-rate card; the supplied Hybrid workbook and valid synthetic report tests do.
No commits, pushes, tags or client release ZIPs are produced.
