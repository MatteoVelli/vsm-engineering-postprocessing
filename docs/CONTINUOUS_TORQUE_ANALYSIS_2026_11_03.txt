ASTAUTO dynamic continuous-torque analysis — Phases 1 and 2
3 November 2026; workspace baseline commit 2734e5147ebc7d17b046af7e18f44db5a5534eed

PURPOSE AND SCOPE

One optional, user-supplied continuous motor curve is assessed against the
current simulation's four actual motor-side speed/torque pairs. No simulation
registration, reference duration, fixed sample count, frequency, motor model,
23-row structure or stored manufacturer curve is required. The existing peak
workflow remains independent. Continuous-only assessment needs neither peak
torque nor gearbox parameters. This is a specification-exceedance assessment,
not a thermal model or proof of thermal failure. No manufacturer Duty Summary
is implemented.

GUI INPUTS AND STATE

The existing Motor Performance Curves (Optional) editor now has three editable
columns: Motor speed [rpm], Motor peak torque [Nm], Motor continuous torque [Nm].
Rows can be pasted, inserted/deleted and cleared. Missing rating cells may
belong to the independent other curve. At least two complete pairs are needed
for a supplied curve. Continuous speed points must be nonnegative and unique;
they are sorted for interpolation. Continuous ratings must be finite and
positive. A row without either rating contributes to neither curve. Peak point order retains the existing behavior. No curve or
drivetrain parameter is populated by default.

Invalid continuous data do not prevent valid peak reporting; invalid/missing
peak or drivetrain data do not prevent valid motor-side continuous assessment.
The GUI shows the unavailable part explicitly. No optional specification means
ordinary reporting with no additional warning or fabricated zero/duration.

The GUI displays maximum segment duration and responsible motor(s), plus a
per-motor table containing maximum segment duration, accumulated exceedance
time, episode count, maximum utilisation, flagged sample count and status.
Accumulated times and episode counts are per motor, not sums over four motors.
All four motors must be available for a complete vehicle maximum. A valid
zero-exceedance assessment shows 0 s, 0 s total, and 0 episodes.

Inputs are scoped by source content SHA-256, absolute path and profile path.
The imported-array cache additionally binds import options; assessment cache
keys include the actual loaded profile and current reporting inputs. Changing
continuous inputs invalidates stale report downloads. Ordinary reruns preserve
input values. Source/profile switches show no old result. Reuse previous motor
specifications for this source explicitly copies only motor specifications and
then recalculates against that source/profile. It never copies manual duration.

The optional externally calculated maximum-duration field is blank by default
and requires finite nonnegative seconds plus external calculation provenance.
It is a fallback only: an available automatic result, including a true zero,
always takes precedence. There is no manual override of an automatic result.
Manual results are labelled Manual fallback in the GUI, slide and provenance.

EQUATIONS AND INTERPOLATION

For the supplied continuous curve (n_j, C_j), at measured motor speed n_i:
  x_i = abs(n_i)
  C_i = C_j + (C_(j+1) - C_j) * (x_i - n_j) / (n_(j+1) - n_j)
  utilisation_i = abs(T_i) / C_i
  above_i = abs(T_i) > C_i

Equality is not an exceedance. Interpolation includes both endpoint RPMs.
There is no extrapolation outside the supplied speed range. Missing/nonfinite
samples, unsupported units or unsupported RPM coverage produce unavailable
status and no complete vehicle duration, rather than an invented zero.

The shared workflow assumes symmetric positive/negative continuous torque
magnitude and uses absolute RPM. This follows Sergio's demonstrated convention;
real motors do not universally have symmetric continuous regenerative ratings.
For signed speed, mechanical power sign distinguishes motoring (n*T > 0) from
regeneration (n*T < 0); the magnitude comparison covers both under this explicit
symmetry assumption. Capability curves are plotted at supplied nonnegative RPM.
Peak torque is never substituted for continuous torque.

The adapter reads track_time and electricsystem_em1..4_speed/torque through the
selected profile's semantic resolution. It does not use CSV column positions,
wheel torque, KERS gearbox torque or a guessed ratio. Explicit channel units
are converted to seconds/RPM/Nm where supported, with conversion factors,
source names/IDs, source SHA-256 and profile recorded in provenance.

EPISODE DURATION POLICY

Require at least two finite, strictly increasing timestamps. Duplicate,
reversed, missing or nonfinite timestamps make analysis unavailable.

Sample i represents the observed interval [t_i, t_(i+1)):
  dt_i = t_(i+1) - t_i for i < N-1
  dt_(N-1) = 0

Group consecutive flagged samples into episodes. Episode duration is the sum
of their observed interval widths. The interval end is the timestamp after the
last flagged sample, bounded by the last recorded timestamp. Accumulated time
is the sum of flagged interval widths; maximum segment duration is the largest
episode duration; episode count is the number of runs. The final flagged sample
still contributes to sample/episode counts and utilisation but adds no time.

No one-second assumption, terminal interval extension or sub-sample threshold
crossing is introduced. Irregular and long positive intervals use the same
declared sample-and-hold policy; no arbitrary dropout threshold is inferred.
Shorter unobserved excursions or crossings between samples cannot be resolved.
A terminal-only exceedance can have one flagged sample/episode and zero
observed duration; this is distinct from a zero-exceedance result.

REFERENCE WORKBOOK INVESTIGATION

Read-only inspection covered Time_Above_Continuous_Torque.xlsx, _03.xlsx and
_04.xlsx, and the updated 25% gradient workbook ending Rough_(4).xlsx, all in
Downloads. The actual 23-point continuous ratings were read from Motor Curve,
not inferred from peak torque. Drive Data uses ABS(speed), linear interpolation,
ABS(torque) > limit, and symmetric generating limits. Segments counts flagged
samples times an explicitly entered one-second interval.

The source has 2161 timestamps from 0 to 2160 seconds. The workbooks count a final
flagged sample as one additional second, yielding 829 seconds. This application
bounds time to the recorded horizon, yielding 828 seconds. Both approaches give
the same required maximum run of 82 seconds. The application does not alter
its definition to force agreement with a reference duration. The updated
Torque Maps workbook provides slightly more precise ratings (maximum difference
5.542233338928781e-13 Nm); an independent rerun gives identical flags and durations.

EXCEL AND POWERPOINT

Torque Maps, both native XY charts and all eight existing local VSM datasets
are retained. Existing FL/FR/RL/RR names, original point values and peak overlays
are preserved. The new continuous table uses BI4:BN(last input row+4), beyond
the existing peak table AX:BG and original simulation blocks ending at AU.
No additional worksheet or separate calculation workbook is introduced.

Continuous input RPM/torque in BI/BJ are blue; BK is the black generator formula.
With explicit ratio/efficiency, BL/BM/BN contain black wheel formulas:
  BK6 = -BJ6
  BL6 = BI6/$BE$4
  BM6 = BJ6*$BE$4*$BG$4
  BN6 = BK6*$BE$4/$BG$4

The shared explicit drivetrain parameters use BE4/BG4. Peak and continuous
wheel overlays must use the same parameters. Without them, no wheel conversion
or wheel capability series is fabricated. Motor-side assessment remains valid.

For the 23-point reference:
  Motor Continuous Torque: X BI5:BI27, Y BJ5:BJ27
  Generator Continuous Torque: X BI5:BI27, Y BK5:BK27
  Positive Continuous Wheel Torque Limit: X BL5:BL27, Y BM5:BM27
  Negative Continuous Wheel Torque Limit: X BL5:BL27, Y BN5:BN27
All references are on Torque Maps and all capability series are native lines.
Peak + continuous + drivetrain produces 8 series in each Electric chart.
Continuous-only without drivetrain gives 6 motor-side and 4 wheel-side series.
Excel editing updates the formula-derived capability lines live. Assessment
metrics/PPT are calculation snapshots: re-run the app after Excel limit edits
to recalculate episode metrics; this is stated in workbook metadata/provenance.

Slide 15 retains both original plot images/geometry, typography, colors and the
16-slide structure. An optional native KPI rectangle occupies existing space
above the maps and reads MAXIMUM SEGMENT TIME ABOVE CONTINUOUS TORQUE. It shows
the current calculated duration, or a labelled externally sourced fallback.
No valid duration means no card. Zero is displayed when calculated accurately.
No automatic capability overlays are added to the approved PowerPoint charts.

The current real reports render 82 s, 7 s, 0 s, a labelled manual 12.25 s, and no
card for the no-input case. Every unrelated slide and all original map picture
bytes/positions are unchanged on the same source. All 25 unrelated native Excel
charts and protected VSM numerical calculations remain unchanged.
