# Sergio change request — 4 November 2026

Motor Torque and Power is implemented in the Electric and Hybrid Excel/PPT
generators using the current run’s editable torque curves. The earlier
external-workbook approach has been superseded.

See [implementation and release verification](MOTOR_TORQUE_POWER_2026_11_04.md)
for generated deliverables, exact source changes, numerical acceptance, tests,
native Office verification and remaining warnings.

The earlier energy-card changes remain: TYRE TOTAL ENERGY, AUX ENERGY and TOTAL
ENERGY receive CONSUMPTION on a second line only once. KPI values are unchanged.
See [configuration guidance](CONFIGURATION_GUIDE.md#motor-torque-and-power-4-november-2026).
