Complete removal of the client-facing Agro Mass Source feature - 24 October 2026
===============================================================================

This supersedes the partial removal described in
archive/2026-10-agro/TEMPLATE_AGRO_WORKFLOW_2026_10_24.txt.
The earlier numerical/source-policy corrections remain intact.

Final targeted changes
-----------------------
src/vsm_postprocessing/ui_app.py:
  Deleted the optional agrochemical source-configuration block entirely, including
  source-policy selection, source/header/provenance fields, physical-interpretation
  controls and its direct-volume/flow source overrides. None remains in Advanced
  Configuration. Battery Pack Mass, density and machine-specification controls
  retain their previous behavior. Source settings remain profile/API configuration,
  not client UI inputs. Supported profiles still resolve automatically.

src/vsm_postprocessing/excel_report_engine.py:
  Replaced _write_agro_source_sheet() with _bind_agro_excel_sources(). The main
  raw/MATH channel reuse rules are unchanged. The fallback no longer creates ANY
  worksheet. Only missing dependencies are placed in unused, hidden columns D:F
  of the Metadata worksheet which already existed before the agro feature.
    D: configured raw force or direct mass, only if it is not exported.
    E: canonical remaining-mass formula, only if main MATH cannot be reused.
    F: cumulative distance, only if it is not exported.
  Existing A:B metadata fields are preserved. No helper vectors duplicate an
  already-bound main input. Columns D:F and the Metadata sheet are hidden.
  Raw/MATH columns, independent export choices and Sergio's visible layout are
  unchanged. No replacement auxiliary worksheet is introduced under another name.

  Diesel's legacy 9.80665 MATH remains untouched; qualified reporting still uses
  9.81 in Metadata E when necessary. Direct kg values use an identity formula,
  without a force conversion. Formula/chart bindings and source coordinates in
  manifests now point to the actual existing main or Metadata columns.

No changes to agro_reporting.py, agro_mass.py, the validated numerical engine,
profile configuration, PowerPoint design or the shared formula compiler were
needed for this final removal. The existing four-metric formula writer already
accepts worksheet/column bindings and therefore follows the new locations.
No numerical or export-selection constraint prevented complete removal.

Safeguards and Excel behavior preserved
---------------------------------------
Capacity, L/m, kg/m and net kg/km Value cells remain real Excel formulas, including
formula-valued N/A cases. Available values depend on raw worksheet data, density
and dynamic analysis-window ranges, not copied final Python results. Canonical
mass uses -Fz/9.81 or the configured direct kg source. Full-recalculation flags
and deterministic initial formula caches remain in place.

Source mapping, units, missing/nonfinite values, force sign, zero signals,
negative contents, refills, discontinuities, density requirements and provenance
retain the established policy. Observed inferred mass is not nominal tank
capacity, measured contents or physically validated spraying. Questionable Caiman
and all-zero Diesel behavior are preserved. Internal configuration-driven sources
are retained; arbitrary forces are never guessed to be chemical contents.
