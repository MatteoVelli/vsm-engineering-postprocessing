Date: 2 November 2026

USER WORKFLOW

Upload a compatible Electric or Hybrid source and use the existing report
workflow. Open "Motor Performance Curves (Optional)" and enable "Include one
shared motor capability curve". Enter or paste motor speed [rpm] and positive
motor peak torque [Nm], then provide a dimensionless final-drive ratio and a
driveline efficiency fraction. Neither parameter has an assumed default.

The table supports dynamic insertion/deletion, including pasting more than
23 rows. Calculated columns appear in a separate read-only preview. Generate
the engineering report normally. Excel receives the capability table and
overlays; the approved PowerPoint generator retains its existing output.

Values survive ordinary reruns and validation/generation. Widget state is
scoped by source SHA-256, source path and profile path. An unrelated source
starts without a curve. "Clear motor curve" resets the optional inputs.
Changing a curve hides an earlier report download until regeneration.

An enabled curve requires at least two complete finite numeric pairs, a
positive ratio, and 0 < efficiency <= 1. Peak torque is a nonnegative magnitude.
Entirely blank insertion rows are ignored; incomplete/nonnumeric rows are
rejected. Signed RPM and the entered point order are preserved. Overflow is
rejected. There is no 23-point limit; the remaining Excel row count is the
storage limit. Numeric blank editor columns prevent ambiguous null schemas.

ASSUMPTIONS AND FORMULAS

The user explicitly supplies one curve shared by all four motors. Generator
peak torque is assumed to equal the negative of motor peak torque, following
Sergio's example. This symmetry is not a universal motor characteristic.

For speed n, peak torque T, ratio r and efficiency e:
  Generator torque = -T
  Wheel speed = n / r
  Positive wheel torque = T * r * e
  Negative wheel torque = -T * r / e

RPM remains RPM, torque remains Nm, and ratio/efficiency are dimensionless.
The motor-shaft and wheel-side charts retain their distinct physical domains.
Only the supplied capability curve uses this explicit drivetrain conversion.
Original VSM/KERS channels and calculations do not use these reporting inputs.

EXCEL STRUCTURE AND EDITABILITY

The existing Torque Maps worksheet, chart positions and eight original VSM
numeric datasets are retained. No Motor Curves worksheet is created. The
additional table starts at AX, beyond the original data blocks ending at AU,
so it does not overwrite existing values or overlap the charts at A6/N6.
A hyperlink at A4 leads to the new table.

For the actual 23-point example:
  Blue inputs: AX5:AX27 RPM, AY5:AY27 peak torque; BE4 ratio; BG4 efficiency.
  Black formulas: AZ generator, BA wheel RPM, BB positive, BC negative torque.
  AZ6 = -AY6
  BA6 = AX6/$BE$4
  BB6 = AY6*$BE$4*$BG$4
  BC6 = AZ6*$BE$4/$BG$4

Capability series references (native Excel XY, continuous straight lines):
  Motor Peak Torque:
    X = 'Torque Maps'!$AX$5:$AX$27; Y = 'Torque Maps'!$AY$5:$AY$27
  Generator Peak Torque:
    X = 'Torque Maps'!$AX$5:$AX$27; Y = 'Torque Maps'!$AZ$5:$AZ$27
  Positive Wheel Torque Limit:
    X = 'Torque Maps'!$BA$5:$BA$27; Y = 'Torque Maps'!$BB$5:$BB$27
  Negative Wheel Torque Limit:
    X = 'Torque Maps'!$BA$5:$BA$27; Y = 'Torque Maps'!$BC$5:$BC$27

The final row follows the supplied curve length. The original simulation
series keep their references, scatter markers, names and values. Wheel legends
remain FL Wheel, FR Wheel, RL Wheel and RR Wheel. Numeric axes scale
automatically, including negative torque. The workbook uses live formulas,
cached initial values and automatic recalculation. Inputs remain editable;
Excel's normal Select Data Add/Edit tools remain available.

Metadata records assumptions, parameter values, formula provenance and table
location. The Excel manifest also retains all supplied points. No curve input
means no additional table, series, metadata record or engineering warning.
