# Deterministic Release Notes - v1.2.1

## Purpose

Version 1.2.1 is a Sergio-fidelity preparation patch on top of the validated v1.2.0 deterministic core. It does not introduce the full 17,418-row duty-cycle composer and does not add AI functionality.

## Validated workflow

```text
VSM CSV/XLSX
    -> inspection
    -> channel selection
    -> math channels
    -> statistics
    -> plots
    -> Excel report
    -> optional PowerPoint report
```

## v1.2.1 changes

- correct source-report top RMS pair: Battery Power RMS + Battery Heatflow RMS;
- battery heatflow helper/statistics added to the default source report;
- source-only PowerPoint is labelled `Source 74 ha Field Cycle` rather than the complete duty cycle;
- client-visible upload hash prefixes and local configuration paths are removed from visible report metadata;
- Milestone 13A.1 formally defines Sergio reference precedence, KPI semantics, time conventions and the 5–80% final-cycle range-extender override;
- 100.0 kWh mission nominal capacity is separated from the 100.77 kWh physical pack reference;
- unresolved Sergio formulas/profile sources remain explicitly documented rather than guessed.

## Reference policy

Sergio's Excel workbook is the primary numerical target for the full mission. The raw VSM workbook is authoritative for the supplied 1,866-row source field cycle. The PowerPoint is used for scenario intent and presentation evidence where it does not conflict with the Excel.

## Client data policy

The Sergio reference Excel/PowerPoint files are validation inputs and are not bundled into the distributable release unless explicit authorisation is provided.

## Acceptance boundary

The deterministic source-only workflow is production-ready for the validated input. The full Sergio 17,418-row mission is not yet generated by the application; that remains Milestone 13B/13C work. Exact full-mission 70-channel equivalence additionally depends on missing road and generator-on reference profile provenance.
